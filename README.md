# AfriLynq Professional B2B Demo

A redesigned AfriLynq frontend direction focused on a mature B2B agricultural marketplace rather than an AI-generated SaaS aesthetic.

## Routes
- `/` — public commercial homepage
- `/marketplace` — marketplace discovery
- `/dashboard` — buyer workspace concept

## Design direction
- Editorial/commercial layout
- Restrained green/ink palette
- Strong typography and grid system
- Real B2B terminology and workflow
- Supplier verification, MOQ, origin and enquiry cues
- Minimal decoration; no gradient-heavy AI styling

The current images are external web-hosted references and should be replaced with AfriLynq-owned imagery before production.
